# Kopdes Merah Putih - Template Website Profil Resmi

Website profil perusahaan (Company Profile) resmi untuk **Koperasi Desa Merah Putih (Kopdes Merah Putih)** yang dirancang modular, profesional, dan siap dijadikan acuan template bagi cabang Kopdes Merah Putih di seluruh Indonesia.

---

## 🛠️ Teknologi & Stack

- **Framework:** React 18
- **Build Tool:** Vite 5
- **Routing:** React Router DOM v6
- **Styling:** Tailwind CSS v3 (Identitas Merah Putih `#DC2626`)
- **Typography:** Google Fonts (Poppins & Inter)
- **Icons & Motion:** Lucide React & Framer Motion
- **Form:** React Hook Form

---

## 🚀 Cara Menjalankan Project

```bash
# 1. Masuk ke folder frontend
cd frontend

# 2. Install dependencies
npm install

# 3. Jalankan development server
npm run dev

# 4. Build untuk produksi
npm run build
```
